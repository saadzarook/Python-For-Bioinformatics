Lesson 7Tables with pandas, part 1

🧬 Why this matters in bioinformatics

So many biological results are tables: genes × samples, reads × quality statistics, variants × annotations. You could handle them with lists and dictionaries, but it gets long fast. pandas is Python's library for tables. Think of it as a spreadsheet you control with code: it handles millions of rows, never "helpfully" turns gene names into dates, and every step you take is written down, so anyone can repeat it.

💡 Loading pandas

pandas isn't built into Python, so this page downloads it (about 8 MB) when you reach this lesson. The first code box may take a few seconds; after that it's quick. Watch the badge at the top of the screen.

Our data: a gene expression experiment

Imagine cells grown in a dish, some untreated (control) and some treated with a drug that damages DNA. DNA damage switches on the protein p53, which turns on genes that pause the cell cycle and repair the damage. RNA sequencing then measures how strongly each gene is expressed, in TPM (transcripts per million): roughly, out of every million mRNA molecules in the cell, how many come from this gene.

expression.csv (made-up teaching data)


  
This table is made-up teaching data, but the genes are real and the pattern is realistic: CDKN1A (p21) and MDM2 are classic genes switched on by p53, cell-cycle genes such as PLK1 go down, and the "housekeeping" genes GAPDH and ACTB stay steady. One value is missing on purpose (FAS, treated): real data has gaps too.


  
DataFrames: reading a table

  
pd.read_csv() reads a CSV file into a DataFrame, pandas' word for a table. Everyone imports pandas with the nickname pd, and calls their main table df.




  
pandas worked out the columns from the header line, turned the numbers into real numbers, and marked the missing value as NaN ("not a number"). The numbers down the left (0, 1, 2…) are the index: a label for each row.

  
With a big table, you don't want to print everything. These tell you what you're working with:




  
.shape is (15, 3): 15 rows (genes) and 3 columns. In .dtypes, float64 means decimal numbers and str means text.


  
Selecting columns

  
Square brackets with a column name give you that column. A single column is called a Series. To get several columns, put a list of names inside the brackets, which is why you see double brackets:




  
Notice that .mean() simply skipped the missing value. We'll come back to missing values in Lesson 8.


  
Filtering rows

  
This is where pandas shines. A comparison on a column gives a Series of True/False, one per row. Put that inside df[...], and you keep only the rows marked True:




  
Usually you write it in one go: df[df["treated_tpm"] > 100]. To combine conditions, use & (and), | (or) and ~ (not), with brackets around each condition:




  

    ⚠️ & and |, not and and or
    
With pandas columns, Python's and and or give an error ("The truth value of a Series is ambiguous"). Use & and | instead, and put brackets around each comparison: (df["a"] > 1) & (df["b"] < 5). Without the brackets, Python works out the & first and the result is a confusing error.

  


  
Sorting




  
Sorting doesn't change df: like string methods, it gives you a new DataFrame, which we stored in top.


  
New calculated columns

  
Assigning to a new column name creates a column, calculated for every row at once. No loop needed! Let's calculate the log2 fold change: how many times the expression doubled (positive) or halved (negative) after treatment.

  
Two details. First, we borrow log2 from NumPy, the number-crunching library that pandas is built on, because it works on a whole column at once. Second, we add 1 to both values before dividing. This is called a pseudocount: it avoids dividing by zero (and the log of zero) for genes that aren't expressed at all, and it stops tiny values like 0.1 → 0.2 from looking like a huge "doubling".




  
Look at the result: the p53 targets (CDKN1A, MDM2, GADD45A, TP53I3, BAX) have log2 fold changes above 1, which means they at least doubled. The cell-cycle genes (MYC, CCNB1, PLK1) went down. GAPDH and ACTB stayed close to 0. That's exactly what the biology predicts. (FAS shows NaN because its treated value is missing: any calculation with a missing value gives a missing result.)


  
Reading TSV files

  
read_csv() reads tab-separated files too: just tell it the separator with sep="\t".




  

    🧹 Good habit: analysis in code, not by hand
    
Filtering and sorting in a spreadsheet by clicking leaves no record of what you did. With pandas, every step is written in your script, so you (or a reviewer) can see exactly how a result was made and repeat it on new data in seconds. That's what reproducible means.

    ✅ Key takeaways
    
    
      
  • import pandas as pd; pd.read_csv(file) reads a table (add sep="\t" for TSV).
    • 
      
  • Look before you analyse: .head(), .shape, .columns, .dtypes.
    • 
      
  • df["col"] selects a column (a Series); df[["a", "b"]] selects several.
    • 
      
  • Filter rows with df[condition]; combine conditions with &, | and brackets. Sort with .sort_values().
    • 
      
  • New columns are calculated for every row at once: df["new"] = df["a"] / df["b"].
    •
