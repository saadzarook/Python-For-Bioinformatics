"Are you ready?" warm-up quiz

Four quick questions about Level 1. Got one wrong? No problem at all: the explanation tells you which Level 1 lesson to peek at, and the links are just below the quiz.

1. If dna = "ATGCGT", what is dna[1:4]?

  • That's dna[0:3]. Remember that Python counts from 0, so index 1 is the second letter. (Level 1, Lesson 3: Strings as DNA)
  • Yes: indexes 1, 2 and 3. A slice includes the start and stops just before the end. (Level 1, Lesson 3: Strings as DNA)
  • Close, but the slice stops just before index 4, so it has 4 − 1 = 3 letters. (Level 1, Lesson 3: Strings as DNA)

2. counts = {"A": 5}. What does counts.get("G", 0) give?

  • Square brackets, counts["G"], would give a KeyError. .get() is the safe version. (Level 1, Lesson 6: Dictionaries)
  • Correct: "G" isn't a key, so .get() gives back the default value you supplied, 0. (Level 1, Lesson 6: Dictionaries)
  • 5 is the value for "A". "G" isn't in the dictionary at all. (Level 1, Lesson 6: Dictionaries)

3. A function has no return line. What does calling it give back?

  • Yes. print() only shows a value; return hands it back. Without return, you get None. (Level 1, Lesson 7: Functions)
  • Printing isn't returning: the printed text appears on screen but isn't handed back. (Level 1, Lesson 7: Functions)
  • It's not an error, just a function that gives back None. (Level 1, Lesson 7: Functions)

4. In a loop over SeqIO.parse("genes.fasta", "fasta"), where is each record's sequence?

  • .id is the first word of the header, like NM_000518.5. (Level 1, Lesson 9: Biopython)
  • Correct: .seq is a Seq object, which you can translate, reverse-complement and more. (Level 1, Lesson 9: Biopython)
  • .description is the whole header line. (Level 1, Lesson 9: Biopython)
