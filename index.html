Level 1: Easy

What is Python?

Python is a programming language: a way of writing instructions for a computer, in text that looks a little like English. Each instruction is called a line of code. The computer carries out your lines one by one, from top to bottom.

Bioinformatics is using computers to make sense of biological data, and Python is its most popular language. You don't need to be "good at computers" or at maths. If you can follow a lab protocol step by step, you can learn to write Python.

🧬 Why bioinformaticians use Python
  • Sequences are just text. A DNA sequence like ATGGTGCATCTG is a string of letters, and Python is very good at handling text.
  • Computers don't get bored. Counting bases by hand in one short sequence is fine. Doing it for 20,000 genes is not. Python can do it in seconds.
  • Lots of ready-made tools. Free add-ons such as Biopython already know how to read sequence files, translate genes and talk to databases.
  • It's the common language. Python is one of the most used languages in biology labs, so there are many tutorials, helpers and colleagues to ask.

Lesson 1Your first Python

🧬 Why this matters in bioinformatics

Almost every analysis ends with showing a result: a sequence length, a count, a warning that a file looks wrong. print() is how your program talks to you. Reading error messages is just as important: it's how you find out what went wrong in a pipeline.

Showing results with print()

print() is a function: a named command that does a job for you. You put what you want to show between the round brackets ( ). Text must go inside quote marks, so Python knows it is text and not a command. A piece of text in quotes is called a string.

Each print() shows its text on a new line. Python runs the lines in order, from top to bottom.

Printing numbers and doing sums

Numbers don't need quotes. Python can also work out sums for you. You can print several things at once by separating them with commas; Python puts a space between them.

💡 Maths symbols in Python

+ add, - subtract, * multiply, / divide. Brackets work like in maths: (2 + 3) * 4 gives 20.

Comments: notes for humans

Anything after a # symbol on a line is a comment. Python ignores it completely. Comments are notes to yourself and to colleagues, like annotations in a lab notebook.

Reading error messages

When Python can't understand or carry out a line, it stops and shows an error message. Errors are not failures. They are clues. Every error message tells you three things:

  1. Where: the line number with the problem.
  2. What kind of problem: the error's name, such as NameError or SyntaxError.
  3. A short description, sometimes with a suggestion like Did you mean: 'print'?

⚠️ Python is picky about spelling

print, Print and PRINT are different words to Python. Only the lowercase print works. Also, every opening bracket ( and quote " needs a matching closing one. These rules about how code must be written are called syntax.

Real analyses juggle many values at once: a gene name, its sequence, its length, a quality score, whether it passed a filter. Variables let you store each value under a clear name and reuse it, instead of retyping a 3,000-letter sequence every time.

Naming rules

  • Use letters, numbers and underscores _. No spaces: write gene_name, not gene name.
  • A name can't start with a number: sample1 is fine, 1sample is not.
  • Names are case-sensitive: Sequence and sequence are two different variables.
  • Choose names that describe the value: gc_percent is much clearer than x.

Variables can change

You can give a variable a new value at any time. The new value replaces the old one. You can also calculate a new value from the old one:

In Python, = means "store the value on the right under the name on the left". That's why reads = reads + 500 makes sense: work out the right-hand side first, then store it.

Every value has a data type, which tells Python what kind of thing it is and what you can do with it. The four basic types are:

Lesson 3Strings as DNA

🧬 Why this matters in bioinformatics

Most biological data starts life as a string of letters. Picking out a codon, cutting out a primer site, counting bases or measuring GC content are all string operations. GC content matters in real work: it affects how strongly DNA strands stick together, which changes PCR primer design and melting temperatures, and it differs between genomes and species.

Indexing: picking out one base

Each letter in a string has a position number called its index. Python starts counting at 0, not 1. You get a letter by putting its index in square brackets:

0A-61T-52G-43G-34T-25G-1

Top: normal index (from the start). Bottom: negative index (from the end).

⚠️ Biologists count from 1, Python counts from 0

Base number 1 of a gene is dna[0] in Python, base 2 is dna[1], and so on. This "off by one" difference is the source of many bugs, so keep it in mind whenever you convert between biology positions and Python indexes.

Slicing: cutting out a piece

A slice gets a stretch of letters: dna[start:stop]. It includes the start index but stops just before the stop index. So dna[0:3] gives indexes 0, 1 and 2: exactly one codon.

A handy rule: codon number n (counting from 1, like a biologist) is dna[(n-1)*3 : n*3]. Codon 7 is dna[18:21].

Length with len()

len() tells you how many characters are in a string, so for DNA it gives the length in bases.

String methods: tools built into every string

A method is a function that belongs to a value. You use it by writing a dot after the value, then the method's name and brackets. Strings come with many useful methods:

MethodWhat it doesExample
.upper()All capitals"atg".upper() → "ATG"
.lower()All lowercase"ATG".lower() → "atg"
.count(x)How many times x appears"GGCG".count("G") → 3
.replace(old, new)Swap every old for new"ATG".replace("T", "U") → "AUG"
.find(x)Index of the first x (or -1 if it isn't there)"CCATGG".find("ATG") → 2
💡 Methods give you a new string

Strings can't be changed in place. raw.upper() creates a new string and leaves raw as it was. If you want to keep the result, store it in a variable, as with dna = raw.upper() above.

f-strings: tidy output with values inside text

An f-string is a string with an f before the opening quote. Inside it, anything in curly brackets { } is replaced by its value. Add :.1f inside the brackets to round a number to 1 decimal place (:.2f for 2, and so on).

✅ Key takeaways
  • Indexes start at 0: dna[0] is the first base, dna[-1] the last.

  • GC % = (G + C) ÷ length × 100.

Lesson 4Lists and loops

🧬 Why this matters in bioinformatics

Bioinformatics is repetition: every base in a sequence, every codon in a gene, every gene in a genome. A loop lets you write the instructions once and have Python repeat them for every item. Lists let you keep many values together, such as all the codons of a gene or all your sample names.

Lists: many values in one variable

A list holds several values in order, inside square brackets and separated by commas. Indexing and len() work just like with strings.

Lists can hold any type of value, such as numbers: lengths = [444, 333, 1182]. An empty list is written []; you'll often start with one and fill it up with .append().

The for loop: do something for each item

A for loop takes each item in a list, one at a time, and runs the indented lines below it for that item.

How to read it: "for each gene in the list genes, do the indented lines". The name gene is a variable you choose; on each round it holds the next item.

⚠️ Indentation matters
  • The for line must end with a colon :.
  • The lines that belong to the loop must be indented (pushed right) by the same amount. Four spaces is the standard. In these code boxes, pressing Tab inserts four spaces for you.
  • The first line that is not indented is outside the loop.

Looping over a string

A for loop works on strings too: it visits one letter at a time. Here we also use a counter that grows by 1 each time round, a very common pattern.

range(): counting with numbers

range() produces a series of whole numbers, which is perfect for positions in a sequence.

  • range(5) → 0, 1, 2, 3, 4 (stops before 5, just like slicing)
  • range(2, 5) → 2, 3, 4
  • range(0, 12, 3) → 0, 3, 6, 9 (the third number is the step size)

🧪 Project part 1: reverse complement

DNA is double-stranded. The two strands are complementary: A pairs with T and G pairs with C, forming base pairs. The two strands run in opposite directions. By convention, we always write a sequence from its 5′ end to its 3′ end.

Top strand:     5′- A T G G T G C A T -3′
                    | | | | | | | | |
Bottom strand:  3′- T A C C A C G T A -5′

Bottom strand written 5′→3′ (read right to left):  ATGCACCAT

So to get the other strand, written the standard way, you complement every base and reverse the order. This is the reverse complement, and you'll need it constantly: for designing primers, reading genes on the "minus" strand, and searching both strands of a genome.

Lesson 5Conditionals

🧬 Why this matters in bioinformatics

Real data is messy. Is this really DNA, or did an N, a space or a protein letter sneak in? Does this gene start with ATG? Is this read's quality high enough to keep? Conditionals let your program make decisions and handle each case differently.

Comparisons: questions with a True/False answer

A comparison checks something and gives back a boolean: True or False.

SymbolMeaningExampleResult
==is equal to"ATG" == "ATG"True
!=is not equal to"ATG" != "TAA"True
< and >less than / greater than55.2 > 60False
<= and >=less / greater than or equal to30 >= 30True
inis found inside"GAG" in "CCTGAGG"True
⚠️ One = or two?

= stores a value in a variable. == asks whether two values are equal. Mixing them up is one of the most common beginner mistakes.

if, elif and else

An if statement runs its indented lines only when the condition is True. elif ("else if") adds another condition to try, and else catches everything that didn't match. Python checks them top to bottom and runs only the first block that matches.

Like for, the if, elif and else lines end with a colon, and the lines that belong to them are indented.

Combining conditions: and, or, not

  • A and B is True only if both are True.
  • A or B is True if at least one is True.
  • not A flips True to False and False to True.

  • TAA is a stop codon (called "ochre").

✅ Key takeaways
  • Comparisons (== != < > <= >= in) give True or False.
  • if / elif / else run only the first block whose condition is True. Colons and indentation are required.
  • Combine conditions with and, or and not.
  • A flag variable (is_valid = True) is a simple way to remember whether a problem was found.
  • Stop codons (TAA, TAG, TGA) only count when they're in the same reading frame as the start codon. break leaves a loop early.

Lesson 7Functions

🧬 Why this matters in bioinformatics

You've written the GC content, reverse complement and translation code several times already. Imagine copying it for every gene in a genome, and then finding a bug: you'd have to fix every copy! A function packages code under a name, so you write it once, test it once, and reuse it everywhere. Every bioinformatics tool is built from functions.

Defining and calling a function

You've already used functions made by others: print(), len(), range(). Now you'll make your own with def (short for "define"):

  • def starts the definition, then the function's name, then brackets and a colon.
  • Inside the brackets is a parameter: a variable that receives the value you pass in. The value you pass in when you call the function is called an argument.
  • The indented lines are the function's body. Defining a function does not run it; it only runs when you call it, by writing its name with brackets.

Giving back a result with return

Most useful functions work something out and hand the answer back with return. You can then store the result in a variable, print it, or use it in a calculation.

The text in triple quotes """...""" just under the def line is a docstring: a short description of what the function does. It's optional, but a very good habit.

⚠️ print is not return

print() only shows a value on screen. return hands it back so the rest of your program can use it. If a function has no return, it gives back the special value None ("nothing"). Run this to see the difference:

Functions can have several parameters

Separate parameters with commas. Variables created inside a function exist only inside it, so they won't clash with variables of the same name elsewhere.

Functions can also call other functions: translate() uses the CODON_TABLE dictionary. (Writing a name in capitals is a convention that means "this value never changes".)

Lesson 8Reading FASTA files

🧬 Why this matters in bioinformatics

Real sequences don't come typed into your code. They come in files, downloaded from databases such as NCBI or produced by sequencing machines. FASTA is the most common sequence file format in biology. Once you can read it, you can analyse any gene, any genome.

What a FASTA file looks like

A FASTA file is a plain text file. Each sequence (called a record) has two parts:

  • A header line starting with >. The first word after > is the sequence's ID; the rest is a free-text description.
  • One or more lines of sequence. Long sequences are split over several lines (often 60 or 70 letters each), so you must join them back together.

The instructions you write for the computer, in a programming language such as Python.

Text after a # that Python ignores. It's a note to explain your code to humans.

A check such as ==, !=, <, > or in that gives True or False.

A description in triple quotes """...""" on the first line inside a function, saying what the function does.

A message Python gives when it can't carry out your code. It names the problem (e.g. NameError) and the line where it happened.

Data saved on a computer under a name, like sample.fasta. Python opens files with open().

        
Float

        
A number with a decimal point, such as 37.5 or 0.25.

Code that repeats its indented lines once for every item in a list, string, file or range.

A named, reusable block of code that does one job, such as print() or your own gc_content(). You run it by "calling" it with brackets.

        
if statement

        
Code that runs only when a condition is True. Can be followed by elif (another condition) and else (everything else).

        
import

        
The command that brings a module or library into your program so you can use it, e.g. from Bio.Seq import Seq.

        
Indentation

        
Spaces at the start of a line. Python uses indentation (normally 4 spaces) to show which lines belong inside a loop, if or function.

        
Index

        
The position number of an item in a string or list. Python starts counting at 0.

        
Integer (int)

        
A whole number with no decimal point, such as 30 or -2.

        
Key

        
The thing you look up in a dictionary. In {"ATG": "M"}, the key is "ATG" and the value is "M".

        
Library (package)

        
A collection of ready-made code written by others that you can import and use, such as Biopython.

        
List

        
An ordered collection of values in square brackets, like ["HBB", "INS"]. You can add to it with .append().

        
Loop

        
Code that repeats. The for loop is the main type in this level.

        
Method

        
A function that belongs to a value, used with a dot: dna.upper(), dna.count("G").

        
Module

        
A single file or section of a library that groups related tools, e.g. Bio.SeqIO or math.

        
None

        
Python's special value for "nothing" or "no value yet". A function without return gives back None.

        
Object

        
A value that bundles data together with methods that work on it. A Biopython Seq object holds a sequence and knows how to translate it.

        
Parameter

        
A variable named in a function's definition that receives the argument. In def gc_content(seq):, seq is the parameter.

        
Parse

        
To read raw text (like a FASTA file) and turn it into a useful structure (like a dictionary of sequences).

        
Pyodide

        
A version of Python that runs inside a web browser. It's what powers the code boxes on this page.

        
Python

        
A popular, beginner-friendly programming language, widely used in science and bioinformatics.

        
range()

        
Produces a series of whole numbers. range(0, 9, 3) gives 0, 3, 6. It stops before the end number.

        
return

        
Ends a function and hands a value back to the code that called it.

        
Slice

        
A piece of a string or list, written [start:stop]. It includes start but not stop.

        
String (str)

        
Text inside quote marks, like "ATGC" or 'insulin'.

        
Syntax

        
The spelling and grammar rules of a programming language: quotes, brackets, colons, indentation. Breaking them gives a SyntaxError.

        
Terminal (command line)

        
A window where you type text commands to your computer, such as pip install biopython. Covered in the Intermediate level.

        
Traceback

        
The full error report Python prints, showing where the error happened. The most important line is usually the last one.

        
Variable

        
A name that stores a value, like a label on a sample tube: gene = "HBB".

      

    

    

      
Bioinformatics terms

      

        
Accession number

        
A unique ID for a record in a database, e.g. NM_000518.5 for the human HBB mRNA at NCBI. The number after the dot is the version.

        
Amino acid

        
A building block of proteins. There are 20 standard ones, each written as a one-letter code (M = methionine, W = tryptophan, …).

        
Base pair (bp)

        
Two bases on opposite DNA strands that pair up (A with T, G with C). Also used as a unit of length: a 444 bp gene.

        
Bioinformatics

        
Using computers and programming to store, analyse and understand biological data such as DNA, RNA and protein sequences.

        
Biopython

        
A free Python library with tools for biology: sequences, file formats, databases and more.

        
Coding sequence (CDS)

        
The part of a gene or mRNA that is translated into protein, from the start codon to the stop codon.

        
Codon

        
A group of three bases that codes for one amino acid, or for "stop".

        
Complement

        
The partner base for each base: A ↔ T and G ↔ C (in RNA, A ↔ U).

        
DNA

        
Deoxyribonucleic acid: the double-stranded molecule that stores genetic information, written with the letters A, C, G and T.

        
FASTA

        
A simple text format for sequences: a header line starting with >, followed by lines of sequence.

        
5′ and 3′ ends

        
The two ends of a DNA or RNA strand, named after carbon atoms in the sugar. Sequences are written 5′ → 3′ by convention, the direction in which DNA and RNA are made.

        
GC content

        
The percentage of bases in a sequence that are G or C. It affects DNA stability and melting temperature, and varies between genes and species.

        
Gene

        
A stretch of DNA that contains the instructions for making a functional product, usually a protein.

        
Genetic code

        
The rules that map the 64 codons to 20 amino acids and 3 stop signals. Most organisms use the "standard" code.

        
Header

        
The line starting with > in a FASTA file. It holds the sequence ID (first word) and a description.

        
Mutation

        
A change in a DNA sequence. The sickle cell mutation changes one base in the HBB gene (GAG → GTG).

        
NCBI

        
The US National Center for Biotechnology Information, which runs major public databases of sequences and scientific literature.

        
Nucleotide (base)

        
A single unit of DNA or RNA, identified by its base: A, C, G, T (DNA) or U (RNA).

        
Protein

        
A chain of amino acids that folds into a working molecule, such as haemoglobin or insulin.

        
Reading frame

        
One way of dividing a sequence into codons. Starting at base 1, 2 or 3 gives three different frames on each strand.

        
Record

        
One entry in a sequence file: a header plus its sequence.

        
Reverse complement

        
The sequence of the opposite DNA strand, written 5′ → 3′: complement every base, then reverse the order.

        
RNA

        
Ribonucleic acid: a usually single-stranded copy of genetic information, using U (uracil) instead of T.

        
Start codon

        
The codon where translation begins, usually ATG (AUG in RNA), which codes for methionine (M).

        
Stop codon

        
A codon that ends translation: TAA, TAG or TGA (UAA, UAG, UGA in RNA). It doesn't code for an amino acid.

        
Transcription

        
Copying DNA into RNA. The mRNA matches the coding strand, with U in place of T.

        
Translation

        
Building a protein from mRNA, reading one codon at a time from the start codon to a stop codon.
