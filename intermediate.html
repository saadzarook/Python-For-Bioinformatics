Default arguments

A default argument is a parameter with a ready-made value. If the caller doesn't give one, the default is used. You've already met one without knowing it: in Biopython's translate(to_stop=True), to_stop is a parameter whose default is False.

Writing as_percent=False in the call, with the parameter's name, is called a keyword argument. It makes calls easy to read: gc_content(seq, False) works too, but what does False mean there? Use simple values for defaults: numbers, text, True/False or None.

No "magic numbers": name your thresholds

A magic number is an unexplained number in the middle of your code, like if len(seq) > 100:. Why 100? Is it the same 100 as on line 80? Give it a name in capitals at the top of your script (you met this convention with CODON_TABLE in Level 1). Capitals mean "a constant: set once, never changed":

Lesson 2When things go wrong

🧬 Why this matters in bioinformatics

Real data breaks programs. A file is cut short, a sequence contains an X, a spreadsheet says n/a instead of a number. A good pipeline doesn't hide these problems or, worse, quietly produce wrong numbers. It stops with a clear message, or deals with the problem on purpose. In this lesson you'll learn to read errors, catch them, raise your own, and test your code so bugs show up early.

First, a reminder from Level 1 that's worth repeating: errors are not failures. They are clues. Everyone gets them, all the time. The skill isn't avoiding errors; it's reading them calmly and working out what they're telling you.

Reading a full traceback

In Level 1 your errors were mostly one line deep. Once functions call other functions, the error report, called a traceback, lists every step that led to the problem. Here's what you'd see on your own computer if you ran this small script, called analysis.py:

💻 analysis.pyon your own computer
def gc_content(seq):
    """Return the GC content of a DNA sequence, as a percentage."""
    return (seq.count("G") + seq.count("C")) / len(seq) * 100


def report(sequences):
    """Print the GC content of every sequence in a dictionary."""
    for name, seq in sequences.items():
        print(f"{name}: {gc_content(seq):.1f}% GC")


samples = {"S01": "ATGGTGCAT", "S02": "", "S03": "GGCC"}
report(samples)

How to read it:

  1. Start at the bottom. The last line says what went wrong: ZeroDivisionError: division by zero.

Catching errors with try / except

Sometimes you expect a problem and know what to do about it. Say your read counts come from a spreadsheet, and someone typed n/a for a failed sample. int("n/a") raises a ValueError. With try / except you can catch that one kind of error and carry on:

  • Python runs the indented lines under try:.
  • If one of them raises a ValueError, Python jumps straight to the except ValueError: block instead of stopping.
  • If nothing goes wrong, the except block is skipped.

Checking your code with assert

assert checks that something is true. If it is, nothing happens. If it isn't, Python stops with an AssertionError and your message. It's the simplest way to test a function: try it on tiny examples where you already know the right answer.

🧹 Good habit: test with small, known examples first

Before running a function on 10 million reads, run it on three bases where you can work out the answer in your head. If it's right on tiny examples, you can trust it much more on big data. The Check my answer button on this page works exactly like this: it's a set of assert lines!

Lesson 4Pattern finding with regular expressions


  

    🧬 Why this matters in bioinformatics
    
Biology is full of short sequence patterns, called motifs: the sites where restriction enzymes cut, the signal that tells a cell where to end an mRNA, the start and stop of a gene. Some motifs are fixed strings, but many are flexible: "G, then A or G, then any base…". .find() only finds one exact string, once. A regular expression (regex for short) describes a whole family of strings, and finds every match.

  


  
Your first regex: finding a restriction site

  
Restriction enzymes are bacterial proteins that cut DNA at a specific recognition site. The famous EcoRI cuts at GAATTC. Molecular biologists use them every day for cloning, so knowing where the sites are in your gene matters.

  
Python's regex tools are in the re module. re.finditer(pattern, text) finds every match, and each match knows where it starts (.start()) and what it matched (.group()). Let's search the complete human HBB mRNA (NM_000518.5, 628 bases). It's saved in this page's folder as efetch_hbb.fasta; you'll see where that file comes from in Lesson 12. To read it we use read_fasta() from our seqtools module:




  
Two things to notice:

  
    
    
  • match.start() counts from 0, like all Python indexes, so we add 1 to report biology positions. (In this mRNA, the coding sequence runs from base 51 to 494, so both sites are inside the coding sequence.)
    • 
    
  • The pattern is written r"GAATTC", with an r before the quote. That makes it a raw string, in which backslashes \ are left alone. Patterns often contain backslashes, so it's a good habit to always write patterns as raw strings.
    • 
  


  
The re module has three functions you'll use most:

    🤓 Did you know?
    
Most restriction sites are palindromes: the site reads the same on both strands. The reverse complement of GAATTC is… GAATTC! That's because many restriction enzymes work as two identical halves, one gripping each strand. EcoRI is named after E. coli strain RY13, the bacterium it was found in, and it was the first enzyme isolated from that strain ("I").

  


  
Flexible patterns: character classes

  
Square brackets mean "any one of these characters". [AG] matches A or G (a purine) and [CT] matches C or T (a pyrimidine). A dot . matches any single character.

  
Biologists write flexible motifs with IUPAC codes: single letters that stand for a group of bases. Each one becomes a character class in regex:

For example, the enzyme HincII cuts at GTYRAC, which is the regex GT[CT][AG]AC. That one pattern covers four different sites: GTCAAC, GTCGAC, GTTAAC and GTTGAC.

The normal gene has a DdeI site right at that spot, CCTGAGG, and the mutation destroys it. Before DNA sequencing was cheap, labs diagnosed sickle cell disease exactly like this: cut the DNA with an enzyme and look at the size of the pieces on a gel.

🧪 Project: finding open reading frames

  
An open reading frame (ORF) is a stretch of DNA that could code for a protein: it starts with ATG, continues in whole codons, and ends at the first stop codon in the same frame. That's a pattern, so let's write it as a regex, one piece at a time:

  


 ATG   (...)*?          (TAA|TAG|TGA)
 │     │                └── then a stop codon
 │     └── any number of codons (... = any 3 bases),
 │         but as FEW as possible (the ?)
 └── start codon


  

  
The ? after * is important. Normally * is greedy: it grabs as much as it can. *? is lazy: it stops at the first stop codon it meets, which is exactly how a ribosome behaves.




  
The first ORF runs from base 51 to 494, exactly the coding sequence that NCBI annotates for HBB (444 bases: 147 amino acids plus the stop codon). The second, short one is just chance: random sequence contains short ORFs all the time.

  

    ⚠️ Limits of regex ORF finding
    
Regex matches never overlap, so an ORF hiding inside another one is skipped, and this only searches one strand. Compare re.findall(r"AA", "AAAA"): you might expect 3 matches, but you get 2. Regex is great for a quick first look; in Lesson 10 you'll find ORFs properly, in all six reading frames.

Lesson 5FASTQ files and quality scores


  

    🧬 Why this matters in bioinformatics
    
A modern sequencing machine reads millions of short DNA fragments in one run, and it isn't equally sure about every base it reports. Along with each base it gives a quality score: how confident it is that the base is right. Almost every sequencing analysis starts with quality control (QC): throwing away bad reads and trimming bad ends. Skip this step, and sequencing errors can look like mutations. In bioinformatics, "garbage in, garbage out" is very real.

  


  
What is a sequencing read?

  
To sequence DNA, it's first broken into many short fragments. The machine then reads the bases of each fragment, one chemical cycle at a time. Each piece of sequence it reports is called a read. On the most common machines (made by Illumina), reads are usually 50 to 300 bases long, and one run can produce hundreds of millions of them.

  
Quality usually drops towards the end of a read, the 3′ end. Imagine thousands of copies of the same fragment being read together, in a cluster. With every cycle, a few copies fall a step behind or jump a step ahead, so the signal gets blurrier and the machine becomes less sure. That's why trimming the 3′ end of reads is so common.


  
The FASTQ format

  
FASTQ is the standard file format for reads. It's like FASTA with quality scores added. Every read takes exactly four lines:

  

    

      
LineStarts withContains

      
        
1@the read's ID (first word) and an optional description

        
2the sequence

        
3+a separator (sometimes the ID is repeated after it)

        
4the quality string: one character per base, so it's exactly as long as the sequence

      
    

  

  
Here's this page's small file, reads.fastq. It holds six 40-base reads. It's made-up teaching data: the sequences are real pieces of the HBB, INS, TP53 and GAPDH genes, and the quality scores were simulated to behave like real Illumina reads, with quality falling towards the 3′ end and a few poor reads.

Those funny symbols on every fourth line are the quality scores. Let's decode them.


  
Phred quality scores

  
Each quality is a Phred score, Q. It's based on the probability P that the base is wrong, on a log10 scale (remember math.log10() from Lesson 3?):

  
Q = −10 × log10(P),   so   P = 10−Q/10

Every 10 points means 10 times fewer errors. Q30 is a common benchmark for "good" data, and Q20 is a common minimum.




  
From characters to numbers: Phred+33

  
To store each score as a single character, FASTQ uses the ASCII code: every character has a number (A is 65, ! is 33). Python's ord() gives a character's number and chr() goes the other way. In the Phred+33 encoding used by all modern machines:

  
Q = ord(character) − 33




  

    🤓 Did you know?
    
Why 33? The first 32 ASCII codes are invisible "control" characters, and number 32 is a space. So !, number 33, is the first visible character, and it stands for Q0. Some older Illumina machines used Phred+64 instead, so the same quality string meant different scores. If your qualities ever come out impossibly high (like Q70), that's a big clue. The name "Phred" comes from a base-calling program written in the 1990s for the Human Genome Project.

    🧬 Why this matters in bioinformatics
    
Results that only live on your screen disappear when you close the window. Real analyses save their results to files: filtered sequences for the next tool, tables for colleagues, spreadsheets for supervisors. And the original data, the raw reads that cost money and time to produce, must never be changed. In this lesson you'll write files safely and in the formats everyone else can open.

  


  
Writing a text file

  
In Level 1 you opened files for reading with with open(filename) as f:. To write, add a second argument, the mode, "w". Then f.write(text) puts text into the file. Unlike print(), .write() doesn't add a new line for you, so add "\n" yourself at the end of each line.




  
As before, with closes the file automatically when the indented block ends. That matters even more for writing: text is only guaranteed to be saved once the file is closed.

    ⚠️ Never modify raw data

Lesson 11Sequence alignment


  

    🧬 Why this matters in bioinformatics
    
Comparing sequences is at the heart of bioinformatics. Is this patient's gene different from the reference? Which gene does this read come from? How closely related are the human and mouse versions of a protein? Answering any of these means lining two sequences up so that matching parts sit on top of each other. That's an alignment. Read mappers, BLAST searches and evolutionary trees are all built on it.

  


  
The idea: line them up

  
Imagine writing two sequences on strips of paper and sliding them until as many letters as possible line up. Three things can happen in each column:

  


ATGGTGCATCTG
|||||-||.|||       | = match    . = mismatch    - = gap
ATGGT-CACCTG


  

  
    
    
  • A match: the same base in both sequences.
    • 
    
  • A mismatch: different bases, for example a point mutation or a sequencing error.
    • 
    
  • A gap (-): a base in one sequence has no partner in the other, because a base was inserted in one or deleted from the other. Together these are called indels.
    • 
  


  
Scoring: how good is an alignment?

  
To compare different ways of lining sequences up, we give each column points and add them up. A simple scoring scheme:

  

    

      
ColumnScoreWhy

      
        
match+1evidence the sequences are related

        
mismatch−1mutations happen, but they cost something

        
gap−2indels are rarer than point mutations, so they cost more

      
    

  

  
The alignment above has 10 matches, 1 mismatch and 1 gap: 10 − 1 − 2 = 7. Different scoring schemes can give different "best" alignments, so always say which one you used.

You met NCBI in Level 1: the US National Center for Biotechnology Information, which runs some of the world's biggest free biology databases, including Nucleotide (DNA and RNA sequences), Protein, Gene and PubMed (scientific papers). E-utilities: NCBI's question-and-answer service

  
NCBI's E-utilities are web addresses that answer questions from programs instead of people. They're an API: a way for programs to talk to each other. The two you'll use most:

  
    
    
  • esearch: "Which records match this search?" It gives back a list of record IDs.
    • 
    
  • efetch: "Send me these records." It gives back the records themselves, for example as FASTA or GenBank text.
    • 
  

  
Your question is written into the web address itself. Everything after the ? is a list of name=value settings joined by &. Spaces and brackets aren't allowed in web addresses, so they're encoded (a space becomes +, [ becomes %5B). urlencode() from the standard library builds this for you from a dictionary:




  
The search term uses NCBI's search syntax: [gene], [orgn] and [filter] say which field each word should match. refseq_select asks for NCBI's one recommended transcript per gene. You can paste that address into your browser's address bar and see the answer yourself!


  
Being a polite user

  

    🧹 Good habit: NCBI's rules for scripts
    
    
      
  • No more than 3 requests per second. NCBI's servers are shared by the whole world. Scripts that hammer them get blocked. With a free API key you may make up to 10 per second.
    • 
      
  • Say who you are. Send a tool name and an email address with your requests, so NCBI can contact you if your script causes problems instead of just blocking it.
    • 
      
  • Use your own email, and never someone else's. And never put your email or API key in code that you share or publish: keep the key in a setting on your own computer (see below).
    • 
      
  • Big downloads (more than about 100 requests) belong on weekends or between 9 pm and 5 am US Eastern time.
    • 
      
  • Download once, save the file, and work from your copy. Don't download the same record again every time your script runs.
    •

Lesson 13Capstone: a mini analysis pipeline


  

    🧬 Why this matters in bioinformatics
    
Every sequencing project starts the same way: raw reads come off the machine, and someone has to check them, filter them, summarise them and report what they found, before any biology can happen. That "someone" usually writes a pipeline: a script that runs every step, in order, the same way every time. In this capstone, you'll build one from start to finish using almost everything from Level 2.

  


  
The plan

  


run42.fastq (raw reads, never changed)
   │
   ├─ 1. measure every read      (Biopython, functions)       → length, mean quality, GC%, N count
   ├─ 2. quality control         (named thresholds)            → passed / failed
   ├─ 3. build a table           (pandas)                      → run42_read_stats.csv
   ├─ 4. keep the good reads     (SeqIO.write)                 → run42_passed.fastq
   ├─ 5. plot                    (matplotlib)                  → quality and GC distributions
   └─ 6. summarise               (f-strings, files)            → run42_summary.txt


  

  
The data is run42.fastq from Lesson 9: 40 reads of 75 bases, made-up teaching data built from real human gene sequences with simulated, realistic quality scores.

  
One new tool: SeqIO.write(records, filename, "fastq") writes a list of SeqRecords to a file. It's the partner of SeqIO.parse(), and it works for FASTA too.


  

    🧹 Good habits you'll see in this pipeline
    
    
      
  • All settings and file names are named constants at the top, so anyone can see and change them in one place.
    • 
      
  • Small functions with docstrings, each doing one job.
    • 
      
  • The functions are tested on tiny examples with assert before they touch the real data.
    • 
      
  • The raw file is only read; every result goes to a new file.
    • 
      
  • The software versions are printed with the results, for reproducibility.
    •

ReferenceGlossary

  
Plain-language definitions of the new terms in Level 2. Underlined words in the lessons link here. For the basics (variable, loop, function, codon, FASTA and so on), see the Level 1 glossary.


  

    

      
Python terms

      

        
API

        
Application Programming Interface: a set of rules that lets one program ask another for data or actions. NCBI's E-utilities are an API.

        
API key

        
A personal code that identifies you to a service such as NCBI, often allowing more requests. Keep it private: never put it in code you share.

        
ASCII

        
A standard that gives every common character a number: A is 65, ! is 33. ord() and chr() convert between them.

        
assert

        
Checks that a condition is True. If it isn't, Python stops with an AssertionError and your message. Used to test code on small known examples.

        
Comprehension

        
A one-line way to build a list or dictionary from a loop: [len(s) for s in seqs] or {b: dna.count(b) for b in "ACGT"}.

        
Constant

        
A value set once and never changed, written in CAPITALS by convention, such as MIN_QUALITY = 20.

        
CSV / TSV

        
Plain-text table formats: one row per line, with values separated by commas (CSV) or tabs (TSV). Readable by Excel, R, pandas and most tools.

        
DataFrame

        
pandas' table: rows and named columns, like a spreadsheet you control with code.

        
Debugging

        
Finding and fixing bugs, for example by printing values in the middle of the code to see where they differ from what you expected.

        
Default argument

        
A parameter with a ready-made value, used when the caller doesn't give one: def trim(seq, n=3):.

        
groupby

        
A pandas operation that splits a table into groups by a column, calculates something for each group, and combines the results.

        
Histogram

        
A plot that sorts values into ranges (bins) and shows how many fall in each: the standard way to look at a distribution.

        
JSON

        
A text format for data made of nested dictionaries and lists, used by many web APIs. Python's json.loads() turns it into Python objects.

        
Keyword argument

        
An argument passed with its parameter's name, such as translate(to_stop=True). It makes calls easier to read.

        
Magic number

        
An unexplained number in the middle of code, such as if q > 20:. Replace it with a named constant.

        
matplotlib

        
Python's most widely used plotting library. Usually imported as import matplotlib.pyplot as plt.

        
Merge (join)

        
Combining two tables side by side using a column they share, such as a gene name. how="left" keeps every row of the first table.

        
Module

        
A file of Python code that other code can import. Any .py file is a module, such as this page's seqtools.py. First met in Level 1.

        
NaN

        
"Not a Number": how pandas marks a missing value. Most calculations skip it; any sum involving it gives NaN.

        
pandas

        
Python's library for tables (DataFrames). Usually imported as import pandas as pd.

        
PEP 8

        
Python's official style guide: lowercase_with_underscores names, CAPITALS for constants, 4-space indents, spaces after commas.

        
Pipeline

        
A script (or set of scripts) that runs every step of an analysis in order, the same way every time: read, check, process, report.

        
raise

        
Stops the program with an error you choose, such as raise ValueError("Invalid base"), unless the caller catches it with try/except.

        
Raw string

        
A string written with an r in front, r"...", where backslashes are kept as they are. Used for regex patterns.

        
Regular expression (regex)

        
A pattern that describes a family of strings, such as GT[CT][AG]AC. Python's re module searches text with them.

        
Reproducible

        
An analysis anyone can repeat and get the same result: the steps are in code, raw data is unchanged, and settings, seeds and versions are recorded.

        
Random seed

        
The starting number for a computer's random numbers. Setting it, with random.seed(42), makes "random" results the same every run.

        
Series

        
One column of a pandas DataFrame: a list of values with a label for each.

        
Standard library

        
The modules that come with every Python installation, such as math, statistics, collections, random, re, csv and json.

        
Traceback

        
Python's full error report. Read it from the bottom up: the last line names the error; the lines above show the chain of function calls that led there. First met in Level 1.

        
try / except

        
Runs the code under try:; if a named error happens, Python jumps to the matching except block instead of stopping.

        
Tuple

        
A small, unchangeable list written with round brackets, such as ("GAG", 2). Functions can return several values as a tuple.

        
while loop

        
A loop that repeats as long as its condition is True. Make sure something inside it moves towards stopping.

      

    

    

      
Bioinformatics terms

      

        
Accession number

        
A unique, permanent ID for a database record, with a version after the dot: NM_000518.5. The prefix shows the type: NM_ mRNA, NP_ protein, NC_ chromosome. First met in Level 1.

        
Alignment

        
Two or more sequences lined up in columns so that similar parts sit together, showing matches, mismatches and gaps.

        
E-utilities

        
NCBI's programming interface: web addresses such as esearch (find record IDs) and efetch (download records) that answer questions from scripts.

        
FASTQ

        
The standard file format for sequencing reads: four lines per read (@ID, sequence, +, quality string).

        
Feature

        
An annotated region in a GenBank record, such as a gene, exon or CDS, with a location and extra details called qualifiers.

        
Gap (indel)

        
A dash in an alignment where one sequence has a base and the other doesn't, caused by an insertion or a deletion.

        
GenBank format

        
NCBI's rich text format for a sequence record: a header (organism, references), a FEATURES table with annotations, and the sequence.

        
IUPAC codes

        
Single letters for groups of bases, used to write flexible motifs: R = A or G, Y = C or T, N = any base.

        
k-mer

        
A piece of sequence k bases long. A sequence of length L contains L − k + 1 overlapping k-mers.

        
log2 fold change

        
How much expression changed, on a log2 scale: +1 means doubled, −1 halved, 0 unchanged.

        
Motif

        
A short sequence pattern with a biological meaning, such as a restriction site or the poly-A signal AATAAA.

        
Open reading frame (ORF)

        
A stretch of DNA that could code for a protein: from a start codon (ATG) to the next stop codon in the same reading frame.

        
Phred quality score

        
A sequencer's confidence in a base: Q = −10 × log10(error probability). Q20 = 1 error in 100, Q30 = 1 in 1,000.

        
Pseudocount

        
A small number (often 1) added to counts before dividing or taking logs, to avoid dividing by zero and exaggerating tiny values.

        
Sequencing read

        
One short piece of sequence reported by a sequencing machine, usually 50–300 bases on Illumina machines.

        
Recognition site

        
The short sequence a restriction enzyme binds and cuts, such as GAATTC for EcoRI.

        
Restriction enzyme

        
A bacterial protein that cuts DNA at a specific recognition site. Widely used in cloning and, historically, in diagnosis.

        
Scoring scheme

        
The points an alignment gets for matches, mismatches and gaps (or a substitution matrix for proteins). It decides which alignment is "best".

        
SeqRecord

        
Biopython's object for a sequence plus its information: ID, description, annotations, features and per-letter data such as quality scores.

        
Substitution matrix

        
A table of scores for swapping one amino acid for another in a protein alignment. BLOSUM62 is the most common.

        
TPM

        
Transcripts per million: a measure of gene expression. Roughly, out of every million mRNA molecules, how many come from this gene.

        
Translation table

        
A version of the genetic code, numbered by NCBI. Table 1 is the standard code; table 2 is the vertebrate mitochondrial code.

        
Quality trimming

        
Cutting low-quality bases off the end of a read (usually the 3′ end) instead of throwing the whole read away.
